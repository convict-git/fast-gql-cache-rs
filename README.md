# assets

Static files the `main` branch's README and docs load by URL, kept here so `main` holds
only the project itself. Nothing here ships in the npm package.

Link to a file with `https://raw.githubusercontent.com/convict-git/fast-gql-cache-rs/dnd-data/assets/<path>`.
Changes land as new commits: never rewrite, rebase or force-push this branch, because
every README version that links here, past ones included, reads from it.
